# E-Commerce Backend API

This project is a backend API for an E-Commerce application built using Node.js, Express.js, and MongoDB.

The application focuses on building RESTful APIs, handling product-related operations, database integration, and modular backend architecture.

---

# Features

- REST API architecture
- Product API routes
- MongoDB database integration
- Modular folder structure
- CRUD operations
- API testing support
- Scalable backend setup

---

# Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- Nodemon
